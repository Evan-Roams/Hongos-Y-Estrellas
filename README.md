# Hongos y Estrellas

Libro web interactivo inicial.

## Archivos
- index.html — estructura del libro
- style.css — diseño, papel, animaciones y responsive
- script.js — escenas, navegación y fondos

## Uso
Abre `index.html` en un navegador moderno.

Los fondos actuales son gradientes temporales. La versión está optimizada primero para teléfonos: una página visible, controles táctiles y navegación por swipe. Los fondos actuales son gradientes temporales; después se reemplazarán por ilustraciones de cada escena y se añadirá música y animaciones específicas.
